# ui-ux-pro-max — breadth: brand, tokens, slides, banners, components

**Licence:** MIT · **Source:** https://github.com/nextlevelbuilder/ui-ux-pro-max-skill · **Absorbed:** 2026-11-07

## What it is
A large, broad design skill: brand systems, token sets, slide decks, banners, component
styling, many templates. Breadth is the point — it has an answer for almost every artifact
type.

## Rules worth keeping
1. **Tokens, not values.** Colour, spacing, radius, and type are declared once and consumed
   everywhere; a hard-coded hex is a future inconsistency.
2. **A type scale is a ratio**, decided up front, not a pile of sizes chosen per section.
3. **Component styling is a system decision**: one button, three sizes, defined states —
   not a new button per page.
4. **Decks and banners are design artifacts with the same rules as pages**, not exceptions.

## What it gets wrong
Its visual register — gradients, glow, "premium" effects — reads as slop in the other half
of this collection, and it adjudicates nothing. It encourages range without restraint.

## Where this landed

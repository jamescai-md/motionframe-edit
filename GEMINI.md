# GEMINI.md

Read [AGENTS.md](AGENTS.md) — canonical instructions for this repository.
Then read `skills/supervision/SKILL.md`.

For the Gemini CLI, install as an extension: `gemini extensions link .`
(the manifest is `gemini-extension.json`). For Antigravity, skills are read from
`~/.gemini/antigravity/skills/` — `./install.sh --target antigravity` links them there.
